# Manual do Cliente (anfitrião)

_Rascunho inicial — expandir com screenshots reais à medida que o UI de templates/CMS for construído._

## Começar
1. Cria conta em `anfitrioes.pt`, confirma o email.
2. Escolhe o plano.
3. Preenche o assistente inicial (nome do alojamento, tipo, número de propriedades).
4. O teu site fica disponível em `anfitrioes.pt/r/o-teu-slug` imediatamente.

## Gerir o site
- `Website` no menu — edita nome, descrição, contactos, fotos.
- (Após Fase 2) escolhe um template e personaliza cores/logótipo sem qualquer código.

## Ligar o Airbnb/Booking
1. Na página da propriedade, copia o link "Exportar calendário" (feed iCal).
2. Cola esse link no Airbnb/Booking como calendário externo — isto evita que reserves a mesma data duas vezes.
3. Para importar as reservas feitas no Airbnb/Booking para o Anfitrião, cola o link do calendário deles na mesma página.

## Gerir reservas do dia a dia
- `Hoje` mostra check-ins e check-outs de hoje.
- `Reservas` e `Calendário` para veres tudo.
- `Preços` para definires tarifas por época/plataforma.
- `Documentos` para o check-in online e exportação SIBA/SEF.

## Faturação
`Conta → Faturação` — gere o teu plano, vê faturas, cancela quando quiseres.
